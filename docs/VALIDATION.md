# Проверки и ограничения

## Выполнено при подготовке repository

- Извлечены выражения DataMashup без запуска Excel-запросов.
- Метаданные модели взяты из локальной выгрузки 27.10.2026; соответствие текущим PBIX подтверждено SHA-256 02.11.2026.
- Сверены количество и состав бизнес-связей, меры/вычисляемые объекты, имена M-запросов и индексы файлов.
- Изменения M-кода ограничены параметризацией путей и нормализацией переводов строк; исходная логика DAX сохранена.
- Проверены ссылки, SVG, отсутствие исходных книг/PBIX и чувствительных путей в этом комплекте.
- Просмотрены настоящие PNG состояний отчёта; копии в assets/screenshots сверены с исходниками по SHA-256. Подписи учитывают видимые выборы, в том числе сохранённый сезон на кадрах с именем no filters.

Power Query и DAX не исполнялись, Refresh/клики в Power BI не проверялись. Сохранённый результат экрана не является новым независимым расчётом. Этот repository — документированный кейс с кодом, без полного набора данных для автономного запуска.

## Наблюдения по настоящим снимкам

Статические кадры показывают внешний вид и выбранные состояния. Они не подтверждают все возможные сочетания фильтров, скорость отклика или независимую корректность показателей.

|---|---|---|

| Общие измерения | Сверить даты/грузы шрота с календарём/справочником, построенными из масла; проверить пропавшие значения. | Не выполнено в этой подготовке |
| Порты и бассейны | Проверить регистр/пробелы, уникальность портов и одинаковый состав бассейнов в масле/шроте. | Не выполнено в этой подготовке |
| Дедвейт | Проверить значения на порогах 5000/15000/30000/45000, null и ошибку типа. Подпись >45 при условии >=45000 отдельно согласовать. | Не выполнено в этой подготовке |

Эти пункты — конкретные сценарии проверки, а не утверждение об ошибке каждого показателя. После выполнения записать входной срез, ожидаемый/фактический ответ, версию и дату. Не выдавать экономию времени или улучшение решений за измеренный эффект без наблюдений.
