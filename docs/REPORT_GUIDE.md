## Пользовательские механики из описания проекта

На основных страницах пользователь выбирает груз и сезон; клики по диаграммам меняют аналитический контекст согласно сохранённым взаимодействиям. Кнопки «Подробнее…» открывают детализацию, где доступны дополнительные фильтры компании и порта. Кнопки возврата ведут на соответствующую страницу рейтинга; сброс реализован через bookmarks.

В Layout сохранены индивидуальные настройки взаимодействий между визуалами. Их наличие подтверждено, но направление фильтрации / подсветки каждой пары не проверялось кликами. Объекты `singleVisualGroup` — группы оформления и переключаемых блоков, а не DAX calculation groups. Используются текстовые блоки, изображения, кнопки и фирменное оформление; они не образуют дополнительные таблицы модели.

## Демонстрационные материалы

В [галерею](GALLERY.md) включены 4 настоящих PNG из авторской подборки. Видимые состояния проверены по изображениям; при копировании пиксели, значения, контакты и оформление не менялись. Имя no filters трактуется как название файла: сохранённый сезон и другие видимые выборы указаны в подписи.

[Схемы компоновки](LAYOUTS.md) в SVG сохранены как дополнительная техническая иллюстрация по координатам и типам visualContainers. Это не снимки работающего отчёта. Отдельные файлы карт, логотипов и иконок из PBIX не извлекались для распространения; они могут быть видны в составе исходных PNG.
