# Подготовка данных в Power Query M

## Поток

Исходный мониторинг → разделение масла/шрота, выбор полей, нормализация и замены, категория дедвейта → промежуточная книга → факты, мощности и справочники в Power BI → DAX TOP 5/остатков/tooltip → обзор и детализация.

## Два этапа обработки

- `source` — выражения из DataMashup внутри подготовительных Excel-книг. Это обработка первичных балансов/мониторинга, а не строки данных из листов.
- `model` — выражения Power Query семантической модели PBIX. Они читают промежуточные книги и формируют факты/справочники отчёта.
- `parameters` — добавленные текстовые параметры путей. Имена исходных запросов и преобразования сохранены; литералы локальных/сетевых путей заменены параметрами. Иного исправления логики не выполнялось.

Промежуточные XLSX могут содержать сохранённые значения. Они не входят в repository. У части справочников нет DataMashup: отсутствие запроса не означает пропуск извлечения.

## Что делает подготовка

- В исходной книге группа дедвейта создаётся M-кодом по порогам 5000/15000/30000/45000. Это upstream-преобразование, а не автоматически созданный Power BI bin.
- Фильтр названий обращается к первому элементу Excel.CurrentWorkbook()[Content]{0}. Порядок таблиц необходимо контролировать; он влияет на результат.
- Таблица замена_прочее содержит столбцы Найти/Заменить и применяется через List.Accumulate к экспортёру, порту и стране. Её реальные строки в repository не включены.
- Портовые мощности и ряд справочников представлены книгами без DataMashup. Их схему можно описать, но отсутствующий M-код не создаётся и не приписывается исходнику.

## Параметры источников

Значение каждого параметра при поставке — `REPLACE_WITH_LOCAL_SOURCE_PATH`. Заменить его локальным путём в своей разрешённой среде; реальные пути в код не включены. Один исходный путь соответствует одному параметру внутри этого кейса. Этапы Excel и Power BI используют отдельные пространства запросов.

| Параметр | Где используется |
|---|---|
| `pSource01` | source: Мониторинг_масло; source: Мониторинг_шрот |
| `pSource02` | model: Мониторинг_масло; model: Мониторинг_шрот |
| `pSource03` | model: Мощность_порт_масло; model: Мощность_порт_шрот |
